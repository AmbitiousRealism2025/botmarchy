# Support

Hermes Bots is an open-source, source-first preview.

## Start here

- Follow the main [`README.md`](README.md) for product setup.
- Give your coding agent [`docs/agent-assisted-setup.md`](docs/agent-assisted-setup.md) for a repeatable source install.
- Run `./scripts/setup-hermes-bots.sh --verify` to repair dependencies and verify the desktop source.

## Ask for help

Use the repository's setup-help issue form. Include:

- the exact step that failed;
- complete error output with secrets removed;
- macOS, Node.js, npm, `uv`, and Git versions;
- the commit from `git rev-parse --short HEAD`;
- whether the failure is local or involves Orgo, Tailscale, Composio, Codex, or Grok.

Never post API keys, OAuth codes, cookies, Tailscale auth keys, SSH private keys, or unreviewed debug archives.

## Service-specific problems

Billing, account access, quotas, and service outages for Orgo, Tailscale, Composio, OpenAI, or xAI must be handled by that service's support team. Hermes Bots maintainers can investigate the product integration but cannot access or change third-party accounts.

## Security

Do not open a public support issue for a suspected vulnerability. Follow [`SECURITY.md`](SECURITY.md).
